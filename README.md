# RTL_to_GDSII_Counter
Designed and implemented an end-to-end RTL-to-GDSII Counter using Cadence Genus, JasperGold, Modus, and Innovus. Achieved 100% IMC functional coverage and 97% Modus DFT coverage, with JasperGold-based assertion verification. Completed synthesis, formal verification, scan insertion, and physical design.
